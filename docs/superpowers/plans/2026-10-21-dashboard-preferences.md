# 商品偏好与摘要仪表盘实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 放大商品名称、弱化价格，支持可撤销的商品“不感兴趣”，将默认摘要阅读改为按群堆叠并可展开的卡片仪表盘。

**Architecture:** 沿用 FastAPI、SQLite 和现有原生 JS/CSS。商品偏好使用本地稳定键，过滤在分类统计和分页前完成；摘要接口增加可选按群分页，展开时用已有要点接口加载该群内容，完整阅读和来源动作复用现有实现。

**Tech Stack:** Python、FastAPI、SQLite、Jinja2、原生 JS/CSS、独立 Chromium。

**Spec:** 用户 2026-10-21 本会话的截图与修改要求；已授权不重复征求意见。

## 约束和检查重点

- 仅隐藏选择的商品及同卖家同名重复发布；不自动屏蔽其他商品或卖家；身份未知时谨慎限定原商品。
- 可恢复；过滤计数、收藏、跨群、改价、批量隐藏均一致；批量请求先验证再写入。
- 按群分页，不把一个群分散到不同仪表盘页；展开不标记已读，保持日期、群、未读、新增和生成结果精确范围。
- 防止迟到的列表、展开、隐藏结果覆盖新选择；群名和消息文本保持纯文本；320px 窄屏无横向溢出。
- 禁止 Codex 内置浏览器；只使用独立 Chromium。凭据和聊天数据不提交。

## 实施记录

- Ruling: “不感兴趣”按同一卖家、交易方向、物品名或打包组件保存，而非按卖家全局屏蔽 — 用户指向单商品且重复发布已折叠 — 名称无法可靠对应的新物品仍可能需要用户另行选择。
- Ruling: 推广聚合卡不提供整卡隐藏，展开后逐项选择 — 避免把同一发布人的其他商品一起隐藏 — 多个不同项目需要分别点击。
- 服务 API 新测试已红绿；两个界面回归脚本已先失败再通过。独立审查发现的打包改价偏好漂移和连续已读切换失真已分别补回归并修复，复核通过。
- 源码独立 Chromium 验证通过：商品隐藏与恢复、22px 商品名 / 16px 价格、13 群 / 396 条隔离快照要点的仪表盘、展开与更多、完整阅读返回、两次已读切换、键盘、筛选、刷新恢复和空状态；1440/1024/768/390/320 宽度无横向溢出。
- 上述 13 群 / 396 条来自生产归档的隔离快照，不是新生成或新增的报告；未将聊天数据提交到版本库。

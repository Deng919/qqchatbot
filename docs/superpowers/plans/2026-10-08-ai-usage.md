# AI 用量与调用上限实施计划

**Goal:** 落实已批准的 P2-06 设计，在现有 AI 连接页展示 API 用量并限制月度 HTTP 尝试次数。

**Architecture:** 独立 SQLite 连接原子预占次数，统一接入 API 客户端，保持业务 JSON 返回契约。账本及带版本的设置保存在归档库，网页接入和模板独立，既有页面只包含和组装。

**Tech Stack:** SQLite、Decimal、FastAPI、Jinja、httpx MockTransport、pytest、Node、PyInstaller。

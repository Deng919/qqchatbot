# 多 AI 接入与用途切换 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 让 QQ Digest 配置多个 OpenAI 兼容 AI，并按用途选择实际调用的连接。

**Architecture:** 扩展 AIConfig 的连接模型，保留 legacy 顶层字段；factory 按 purpose 解析连接并复用现有 AIClient。设置 API 通过 ConfigFileStore 原子写入连接元数据和密钥路径，前端在同一设置页管理连接。

**Tech Stack:** Python、Pydantic、FastAPI、YAML、现有原生 JavaScript 测试。

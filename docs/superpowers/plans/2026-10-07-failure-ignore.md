# 异常忽略 Implementation Plan

**Goal:** 在异常处理页加入单条忽略、一键忽略待处理及恢复待处理。

**Architecture:** 独立表保存记录 ID、完整异常指纹和忽略时间。读取时只将仍未处理且指纹匹配的异常标为已忽略；重试中及真实恢复优先。批量提交明确的记录快照，在数据库写事务内校验，避免忽略后来出现的异常。

**Tech Stack:** SQLite、FastAPI/Pydantic、原生 JavaScript、pytest。

- [x] 编写并运行服务与 API 失败测试：持久化、撤回、群范围、指纹变化、新异常、重试保护、原子回滚及鉴权。
- [x] 在 archive.py 添加独立表，在 failure_center.py 实现指纹、状态叠加及事务操作；独立 failure_ignore_routes.py 注册登录保护路由。
- [x] 修改 failures.html：四项统计、已忽略筛选、单条和批量按钮；操作期间禁用按钮，丢弃过期读取结果。
- [x] 运行相关回归和全套检查，审查实际差异，完成桌面及窄屏浏览器操作验证。
- [x] 构建独立本机版本，验证打包内容、更新桌面入口和版本登记；不操作用户的真实异常记录，不终止正在运行的旧程序。

验收：忽略不改写任务结果；忽略后的记录不再进入待处理提醒；相同来源后来发生的新异常可见；批量仅影响当前显示的待处理快照；已忽略可恢复，运行中不可忽略。

# P2-02 归档问答设计

继续用户已授权的路线图优化。查找旁增加归档问答入口，独立功能开关默认关闭；页面即使关闭也保留入口和开启指引。

输入问题、群、开始与结束日期，关键词可选，不填则从问题提取中英文词。利用 P2-01 本地索引在指定范围寻找最多 200 条候选，按关键词相关性选择上下文，最多 40 条、16,000 字符。预览明确本地范围与实际发送片段，用户点击发送后只调用兼容 API 通道，公开版仍限定官方 DeepSeek。未命中不调用 AI，显示无法确认。

预览生成随机票据，绑定登录会话、范围、问题、消息指纹和实际片段；保留最近 20 份，15 分钟失效。重复发送相同票据返回缓存结果，正在发送拒绝重复请求。工作线程持有操作锁直到结束，网页断开不会提前放锁；发送前校验来源仍在归档。只接受本次实际发送的 s1/s2 来源标识，拒绝虚构引用和同 ID 跨群误关联；没有有效引用则覆盖为无法确认。来源点击展示范围内的原文，超出日期和群的消息不开放。

登录 cookie 包含随机 nonce 并参与 HMAC 签名，避免同秒独立登录共享票据；旧版二段 cookie 不再接受，升级后重新登录。默认日期、查询边界和来源显示统一使用配置的摘要时区。配置异常统一返回脱敏 503；测试缺密钥时替换配置解析，并禁止构造真实网络客户端。

聊天、问题均为不可信数据，系统提示限制模型根据提供片段作答。此方案不能自动识别全部同义词，答案仍需读者核对来源；片段预览支持修改关键词重新查找。结果不持久化、不新增追问历史，不承诺检索覆盖整库所有相关讨论。

验证：零证据零调用、跨群重复 ID、日期零点、非法来源、内容变更、票据过期/会话隔离/重复与并发、鉴权与开关、宽窄屏预览和来源、高亮转义；合成 AI 不联网，完整回归。实现拆分业务、网页路由、页面和交互模块，主 app 只组装。

# 功能开关

用户选择先隐藏扩展功能。设置页增加“功能开关”，提供精简界面、全部开启及逐项选择。总览、群组、手动采集、搜索、摘要、AI 配置与设置保留。可关闭跨群补看、待办、异常处理、审核、摘要问答、版本纠错、历史巡检；自动采集和自动日报独立开关，不受界面预设影响。

SQLite 保存开关与修订号，随已有备份和迁移保留；未保存开关的旧数据默认全部开启以保持兼容。本次按用户选择保存精简预设。关闭不删除内容，不中止在途工作；扩展入口与操作隐藏，直接访问停用功能页面跳到设置，API 返回明确 403。历史巡检关闭时停止新的自动巡检；自动日报与自动采集关闭时停止后续调度，手动运行可用。开启后恢复数据和入口，无需重启。审核关闭只暂停人工审核入口，摘要仍可记录候选，知识文件保留。

基础摘要持续保存版本快照作为数据保护，关闭版本纠错只隐藏/停用查看历史、纠错和重生成操作；摘要问答不依赖版本面板是否开启。既有通知渠道、备份、自启设置保持独立。并发设置使用修订号防止旧页面覆盖新状态。设置页重载后即时更新全部入口；保存失败保留选择供重试。旧浏览器页可能暂留按钮，但服务端始终按最新开关阻止新操作。

验证：持久化、严格布尔与未知键拒绝、并发冲突、鉴权、全部关联路由、总览/搜索/报告次级入口、自动任务暂停和重开、宽窄屏真实交互。合成 QA 不读真实消息、不调真实 AI。发布到 `D:\Apps\QQDigestDesktop-2026-10-02-Features`，更新用户已授权的桌面快捷入口；实际 EXE 启动受此前自动审批拦截限制。

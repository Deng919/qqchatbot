# 二手原消息配图验收

日期：2026-10-24

## 行为及来源边界

- 二手卡片和详情按精确群号、消息 ID、来源键与转发路径读取配图。列表最多六张，详情最多一百张，延迟加载；保留原有紧凑排列。
- 图片显示独立于 AI 识别开关；继续要求登录、已启用二手群和未屏蔽来源，转发中的不同子消息不能串图。查看图片不调用 AI。
- 默认原图接口保留 MD5 严格校验。新增独立的「本机预览」：仅从配置 QQ 账号的摘要命名缓存读取，忽略消息提供的任意路径；校验非链接普通文件、16 MiB、支持格式、8192 边长及两千万像素，转成最长 1600 像素且不带元数据的 JPEG，在后台线程完成。
- NTQQ 采集补读 `files_in_chat.db`，只读匹配群号、时间、消息 ID 和有效 MD5。与文字合并要求同 ID、同时间，已有更完整的图片元数据优先，异常保留采集不完整状态。
- 事实：本机文字索引更新到十月，消息图片快照只到八月。图片目录还可提供部分十月图片。部分缓存为有效图片但字节 MD5 与目录名不同；原因未经确认，因此不能称为已验证原图。
- 单独发送的图片保留发送人、时间及原消息上下文，不凭相邻时间或同一卖家认定属于某商品。现有商品文本没有同 ID 图片引用，不声称全部旧商品卡片都有照片。

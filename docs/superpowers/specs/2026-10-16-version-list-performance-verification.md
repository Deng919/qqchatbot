# 版本列表性能优化验收

日期：2026-10-16。依据：[设计](2026-10-16-version-list-performance-design.md)与[计划](../plans/2026-10-16-version-list-performance.md)。

## 结果与行为

同机同为 32 个已登记历史包，cProfile 的 `ReleaseRegistry.snapshot()` 从 **87.986 秒降至 0.618 秒**；旧路径 86.984 秒用于遍历程序包，新路径无 `_files` 调用。前后均为带性能采样的单次测量，不作为其他机器的固定耗时承诺。

列表检查受管理路径、登记元信息及 release.json 的 SHA-256 指纹，显示“操作前校验文件”。`valid` 在列表返回中仅表示登记清单有效，不表示历史程序文件刚刚完整校验。切换／回退／清理不信任列表结果，仍重新读取并全量验证包内容、清单、运行占用、互斥及数据路径保护。

真实隔离 EXE 的完整 API 仍会先校验当前运行包：四次宽窄屏请求分别约 **2.191、2.067、2.513、2.521 秒**。源码浏览器使用真实登记列表的只读 bridge，约 0.299／0.294 秒，不能与完整 EXE 请求混称。未增加缓存、线程池、持久状态、新 API 或自动清理。

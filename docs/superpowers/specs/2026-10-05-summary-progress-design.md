# 摘要生成进度

用户要求在生成摘要时添加进度条和状态。沿用现有生成流程，以完成群数计量真实进度。

- 进度条为已处理群数 / 所选群数；单群 AI 调用过程中不虚构百分比。
- 当前状态显示准备、检查本地消息、AI 生成、保存摘要，以及当前群名称。
- 分别统计生成、复用、跳过和失败；单群失败后继续后续群，部分失败明确提示。
- 主阅读页及生成面板都显示同一份进度；收起面板不影响生成。
- 后端保留最近 20 次进度快照及结果，只存在内存，不保存消息或凭据。经现有登录认证访问。
- 请求使用 UUID 标识，重用相同标识不得再次启动 AI。刷新页面可找回最近的生成状态和结果；程序重启后明确不存在状态。
- 原同步 POST API 保持兼容，新增可选 generation_id 和只读进度 API。每秒串行轮询，不重叠；读取失败保留进度并提示重新连接。
- 只有实际成功、复用、跳过或失败才增加完成数。异常终止保留真实完成数，不强制显示 100%。

验证：多群服务阶段、复用/跳过/失败、认证与冲突、并发读取、请求去重、前端轮询断线恢复、刷新恢复、宽窄布局。用模拟 AI，不触碰真实消息或账户。

# 辅助操作图标化

沿用用户选定的浅色卡片示例，将收藏、取消收藏、详情、来源、已读、编辑、删除、不感兴趣、屏蔽等辅助操作改为小方块图标。桌面悬停及键盘聚焦显示完整文字；触屏或窄屏显示简短说明。生成、更新、筛选、分页及表单提交保持文字入口。

## 实现与边界

- 共用 `action_icons.html` 仅增强外观，保留原文字、点击处理器、链接、禁用状态和业务接口；动态新增与状态更新使用同一套增强规则。
- 根据已知操作名匹配图标；搜索历史和目的话题选择中的文字属于用户内容，明确排除。未知标签保持原文字；映射使用无原型字典。
- 提示使用浏览器顶层 popover，避免卡片滚动容器及模态弹窗裁切；窗口缩放、滚动、关闭及按钮移除时收起。
- 不新增数据表，不调整 AI、采集、摘要生成及收藏服务逻辑。原商品名字号与价格层级保持原样。

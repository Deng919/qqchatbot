# P1-07 首次使用引导

从设置页常驻「首次设置」和空摘要页进入六步流程：数据源、群聊、导入、AI、计划、预览。沿用现有界面；每步只展示必要输入、实际状态和可执行的修复提示。已有用户不强制跳转。

## 行为与边界

- 数据检测仅列出本机 QQ 账号目录，不解密、不读密钥。显式「读取当前 QQ」才刷新源库，输出固定到 `D:\Cache\QQDigestSources\<账号>`，验证解析后的路径，禁止写入原 QQ 库。也支持填写已有解密库绝对路径，读取验证后保存。
- 群聊来自真实源库，选择最多 100 个。保存仅添加新群、启用选中的旧群，保留旧群其他选项，不删除或停用未选群。
- 初次导入按群执行，日期最多 31 天，默认最近七天；去重写入，手动导入不推进同步游标。结果逐群持久化，刷新可恢复，失败可以单群重试；不会自动重复执行未完成请求。
- 配置文件原子替换，仅修改相关字段，保留其他字段。SHA-256 版本检查阻止多窗口和外部编辑覆盖。运行中的 Config 对象保持身份，保存后配置生效。操作锁由工作线程持有，页面断开不会提前释放。
- AI 支持本机订阅桥接和兼容 API；填写地址、模型和可选 API Key，密钥沿用项目已有的受限权限文件存储，不返回内容。连接测试只发固定合成文本，必须点击才调用。允许暂不配置 AI，此时不能开启自动日报。
- 开始修改引导配置后，暂停自动采集、日报和历史巡检；完成后按计划和已有功能开关恢复。计划可设置采集间隔、每日时间与两项自动开关；保持其他扩展设置。已有源库账号为零时不允许开启需要 QQ 刷新的自动采集。
- 预览显示本次选群、日期范围的归档数量及真实消息样本，明确仅代表可读本地记录。完成前必须每个所选群在同一日期范围成功导入（零条也如实显示），AI 可跳过；完成后可进入摘要页显式生成。
- 新模块负责配置持久化、引导业务和网页接口，app.py 只接入和调度门控。不修改真实 QQ、账号文件、用户配置来验收。

## 验收

使用合成 SQLite QQ 源库完成六步、重开恢复、重复导入、部分失败重试、配置冲突、原子写失败、鉴权、密钥不回显、计划保存和来源范围测试。真实浏览器验证宽窄屏、恢复及失败提示。全量回归后打包，使用独立合成配置验证实际 EXE，更新已有快捷方式并记录路径。

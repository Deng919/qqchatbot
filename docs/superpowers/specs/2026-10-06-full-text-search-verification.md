# P2-01 检索验收记录

## 结果

新增消息索引、发送人 QQ 号与消息类型组合筛选。摘要、知识不接受消息专属筛选；原消息上下文、字面匹配和安全高亮保留。旧库回填、增量及原生 SQLite 更新、删除、重复导入和回滚均有测试。

消息全文索引在 `qq_digest/message_search.py`，搜索端点移入 `qq_digest/web/search_routes.py`；没有扩大网页主程序职责。摘要显示清理同时保留，上次正文中来源编号与标题星号不再显示，来源数据仍保留。

## 规模验证

数据为 100,000 条合成中文短消息，关键词“接口配置”共 10 条匹配，按原排序核对 ID 完全一致。每种方案执行 5 次取中位值：

| 项目 | 本机结果 |
| --- | ---: |
| 首次回填索引 | 3.01 秒 |
| 原 LIKE 查询 | 108.52 毫秒 |
| 索引候选加 LIKE 校验 | 0.52 毫秒 |
| 数据库原大小 | 25.26 MiB |
| 建索引后 | 36.38 MiB |

查询计划确认 FTS 虚表匹配并通过 rowid 访问原消息。结果是热缓存、短消息和选择性关键词的本机测量，不保证所有数据和宽泛关键词都具有同样速度。

合成数据、脚本与 JSON 结果位于 `D:\Cache\QQDigestFullTextSearch-2026-10-06`，没有读取真实 QQ 数据或发送 AI 请求。

## 浏览器

实际 FastAPI 工作台运行在临时端口 61981，独立合成配置；1280×900 与 390×844 检查通过，没有横向溢出。组合条件匹配 25 条，第二页 5 条；刷新保留发送人、类型、群、日期和页码。“不限日期”提交后刷新保持“最早 至 现在”。查看原文正常，测试 SVG 标签作为文字显示，结果没有产生 SVG 节点，命中高亮正常，控制台无警告或错误。

已有合成摘要在实际报告详情中显示“接口配置：文件已发。”，正文不包含星号或引用编号，仍可通过来源入口查看消息。

## 审查修正

最终全量测试：907 passed、1 skipped、1 warning，耗时 272.05 秒。跳过项为 Windows 符号链接权限测试，警告为已有 Starlette/httpx 弃用提示。新消息索引测试 22 项通过，查找交互与摘要正文／版本切换 Node 回归通过，git diff --check 通过。

独立只读审查提出并复核了三项修复：现有虚表不能替代 FTS5 能力探测；降级期间停用同步必须清除索引就绪标记，恢复后完整回填；不限日期链接刷新不能自动添加最近七天。补充了回归测试与索引回填失败时的事务回滚检查。

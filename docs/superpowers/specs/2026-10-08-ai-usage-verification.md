## 已实现

- 在已有「设置 → AI 连接」增加 API 用量卡片：当前自然月次数、成功／失败及失败比例、结果未知／处理中、已知输入输出 token、用量未知次数、已知费用小计和费用未知次数。
- 月度调用上限默认 0（不限）。次数代表 HTTP 尝试，包括失败、重试、无效 JSON 后的重试与连接测试；被上限阻止的请求不计数。失败比例为已确认失败次数除以当月全部尝试次数，未知和处理中另列。
- 新账本随原归档 SQLite 保存，以专用连接和 `BEGIN IMMEDIATE` 原子预占；取得写锁后读取时间，按账本首次保存的时区决定月份。修改摘要时区不重置额度，过期处理中记录转未知且不退次数。
- API 工厂和所有直接 API 客户端均接入：日报、范围摘要、再生成、报告问答、归档问答、图片／扫描 PDF、首次设置与 AI 设置连接测试。上限错误不重试、不触发付费备用请求；开发专用本机桥接不计 API 次数，公开版仅 DeepSeek 的限制保留。
- JSON 解析失败、HTTP 错误和业务校验失败记为失败；网络结果无法确定记为未知。业务响应仍是字典，内部属性不进入 JSON，业务层可按确切响应纠正该次结果，不依赖共享的“最后一条”记录。纠正不修改 token、费用或次数。
- 附件超限显示「调用上限暂停」。恢复额度后普通准备流程也可重读；成功缓存与本地文件正文提取继续可用。原消息、群权限和既有阅读数据未重置。
- 设置保存严格校验上限、费率和版本，并遵守原业务互斥。费率按接口来源和模型保存每百万 token 的缓存命中／未命中／输出价格，每次调用保存费率快照。缺少 usage、缓存拆分或必要单价时记未知，不假定为 0。不预填厂商价格，不承诺人民币账单上限。
- 账本只保存时间、接口来源、模型、用途、状态、数字用量和费率，不保存聊天、文件正文、密钥、完整错误或原始响应。旧请求不补造用量。

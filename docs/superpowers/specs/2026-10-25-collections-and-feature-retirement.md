# 收藏归并与功能退场

用户确认：收藏与知识库合为一个收藏入口；话题跟踪和待办删除。

## 产品行为

- 日常导航保留一个“收藏”，进入后可切换“已收藏”“整理的资料”，开启人工审核时显示“待确认”。沿用现有两套持久化数据，不复制条目、不破坏原消息引用。
- `/bookmarks` 为统一入口，`view=knowledge` 展示已有知识资料；旧 `/knowledge` 链接携带筛选、条目参数重定向到统一入口，候选审核继续可用。
- 收藏原消息后，可在详情中“整理成资料”；原有保存知识操作统一使用“整理成资料”措辞，成功后进入收藏内资料页。
- 移除独立话题跟踪、待办页面、接口、导航、功能开关、相关操作和到期待办提醒。旧功能开关即使为 true 也不能恢复这些功能。
- 清理不再使用的功能源码、模板和专属测试。历史数据库表、记录保留，兼容历史摘要与备份；普通摘要的讨论主题不属于独立话题跟踪，继续保留。

## 约束与验收

- 不删除个人历史数据库数据，不接触凭据或现有本地配置；不丢失已有收藏、资料和引用。
- 普通群与二手群现有边界、图片预览与下载、会话鉴权、数据操作互斥保持有效。
- 回归覆盖历史链接、功能关闭、旧开关、已存在的到期提醒规则、移动端与真实浏览器操作。
- 独立 Chromium / WebView 测试，禁止 Codex 内置浏览器自动化。
- 源码、测试、必要文档提交并推送当前工作分支；打包更新用户桌面版本。

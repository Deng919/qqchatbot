# 报告限制提示的范围修正

用户确认把单份报告的限制与当天整体任务情况分开展示。

## 修改

- 正常输入的报告不显示覆盖标签。消息较少、输入截断、预处理过滤、采集范围异常分别显示具体原因；缺少有效统计继续显示范围无法确认。
- 当天其他群失败、跳过或输入受限，不再改变当前报告的状态或输入说明。当天整体情况单独显示在详情统计区域。
- 仅对该群自己的失败检查旧报告：结合失败阶段和发布时间，采集／生成失败可提示正在显示之前的报告。通知失败及失败后已重新生成的报告不被误标。旧阶段缺失时仅使用任务异常措辞。
- 已有报告读取时重新计算状态，无需重新生成。

- 独立打包 WebView 实际点击历史摘要、管理报告、打开详情：仅消息少的报告显示标签，正常报告保持正常，详情单独展示当天整体情况。

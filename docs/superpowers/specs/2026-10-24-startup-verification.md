# 桌面启动与自动登录验收

日期：2026-10-24

## 改动与边界

- 原启动流程在未监听的本地端口上重复进行三次 HTTP 探测，本机测得合计约 4.55 秒。现在先尝试独占绑定回环地址，确认端口空闲即可跳过 HTTP；已有服务仍检查健康状态、配置签名和后端版本。
- 原生桌面使用独立签名域、有效期 120 秒的随机启动凭据换取正常会话。凭据仅放在 URL fragment 中，加载页立即清除，并通过同源 POST 交换；不会放进 HTTP URL 查询或访问日志。
- 交换接口仅在带原生桥接的桌面服务启用，检查回环客户端、Host 和 Origin；凭据单次消费有锁保护，过期和重放被拒绝。正常 Web 会话不能充当启动凭据。
- 会话 Cookie 保留 HttpOnly 和 SameSite=strict；业务 API 认证保留。普通浏览器和命令行 Web 服务仍需密码登录；没有改动已有密码或会话密钥配置。

## 验证

- 新增 11 项启动回归，覆盖空端口不请求 HTTP、正常交换、重放、过期、并发消费、外部客户端／Origin 拒绝、签名域隔离、fragment 及普通 Web 服务不开放交换入口。先观察缺少实现时的失败，再验证修复。
- 185 项相关 Python 回归通过，覆盖桌面、Web、更新器、公开发行和摘要读取；本轮没有重跑 Python 全量。
- 冻结安装包独立进程、新建隔离 WebView2 配置，复制真实归档并关闭测试副本的自动任务、备份与清理。旧版两次从进程启动到登录页可交互为 6.969／6.730 秒；新版三次到摘要内容就绪为 2.066／1.959／1.863 秒。对应后端就绪为旧版 5.638／5.326 秒，新版 1.023／0.779／0.791 秒。
- 上述为同机顺序运行的进程启动测量，不是系统重启后的磁盘冷缓存基准；旧版终点是登录页，新版终点是摘要内容就绪，不包含用户输密码耗时。
- 新版三次均直接到 `/reports`、无密码输入框、fragment 已清空、会话为 HttpOnly。两个原生窗口复用同一服务均可进入摘要，关闭第二个窗口后原服务继续运行；未认证浏览器 API 返回 401。
- 安装包 120 个模块、56 份模板与当前源码一致，2192 个清单文件校验通过。

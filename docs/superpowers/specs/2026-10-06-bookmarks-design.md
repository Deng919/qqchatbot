# P1-06 收藏与稍后处理

沿用用户已授权的路线图实施范围。顶部增加「收藏」入口，默认开启，可单独关闭；关闭保留收藏数据。各来源旁增加「收藏」按钮，列表默认显示待处理，可切换已完成、全部及类型筛选、关键词搜索。

支持归档原消息、摘要阅读中的单条要点、资源候选、已入库知识。客户端只提交来源标识，服务端读取和验证真实内容，保存完整文字快照及来源信息。消息以群与消息 ID 去重，摘要以日报/多日摘要 ID 与要点 key 去重，资源及知识分别以候选 ID 去重。重复收藏保留已有状态和内容。

列表可打开收藏详情、查看原内容、标记完成或恢复待处理、取消收藏。快照始终可读；来源删除或摘要改写后明确显示来源不可用，不自动替换成另一条内容。原消息可在收藏详情加载前后上下文，知识链接独立于知识整理开关，资源链接仅允许 HTTP(S)。来源入口受相应功能开关约束。

SQLite 新增 bookmarks 表，记录 source_key、kind、group_id、snapshot、status、revision、created_at、updated_at。状态更新和取消要求 revision，防止多窗口覆盖。写入复用全局操作互斥。收藏进入现有数据库备份；明确删除群全部数据同时删除该群收藏。普通来源文件缺失只影响打开来源。

服务、路由、列表模板分别独立，app.py 只负责注册。验收覆盖认证、开关、严格参数、四类来源、伪造来源拒绝、重复点击、版本冲突、分页搜索、来源消失、群删除、重启保留、桌面打包；浏览器使用合成数据验证收藏到完成/恢复/取消流程及手机布局。

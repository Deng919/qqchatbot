# 交互一致性修复设计

用户已批准交互审查中优先修复的六项建议。本轮修复审查编号 01–06，其余问题保留在审查记录中。

1. 群列表完整返回图片和文件读取设置；缺失字段在详情中显示不可编辑，保存不提交未知值。
2. 备份预览绑定输入路径和请求版本；输入变化作废结果。提交前再次核对，恢复过程中冻结相关输入；显示已校验的实际来源路径。
3. 待办状态操作只提交状态。正文编辑使用整数 revision 做原子并发检查，冲突返回 409 并保留草稿，不自动重发旧值。旧数据库添加 revision 默认 0。
4. 迁移或恢复改变启动配置后，运行中的旧服务进入等待重启状态。统一拦截后续变更请求，自动任务和后台写入停止；读取现有内容、登录和退出仍可用。等待状态显示全局提示；新服务打开新配置后解除。
5. 归档问答预览只查询文字和已有附件识别缓存，不能下载、补采、识图或调用 AI。下一步回答继续使用所选证据。
6. 报告问答绑定当前报告版本的正文和精确时间窗，沿用报告边界的包含／排除语义。无精确时间窗的旧报告按日期处理；损坏的精确窗口拒绝使用。

所有验证使用合成数据和模拟 AI。通过服务、接口、浏览器及打包验证后更新本机安装目录，保留上一版本回退。此轮不发布 GitHub 或公共安装包，不修改真实用户存储设置。

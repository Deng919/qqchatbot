# 常用任务的操作顺手程度复核

本轮按正常用户的任务顺序检查，而不是仅看按钮能否调用接口。场景包括读本群历史、打开对应日报、选择生成范围、找消息、找二手商品、从空结果恢复、保存设置及确认当前状态。

## 已调整的操作

| 用户意图 | 原先的不顺手之处 | 当前行为 |
| --- | --- | --- |
| 看本群历史 | “历史摘要”清掉群聊、阅读条件和报告类型，需要重新选 | 只扩大日期；“清除筛选”才完整重置 |
| 看某日日报 | 从日报卡片进入却恢复了无关旧日期 | 入口明确携带对应日报日期和范围 |
| 知道正在看什么 | 自定义日期／群藏在折叠区，空结果像首次未设置 | 折叠标题显示当前群与日期；空结果明确为当前范围暂无摘要 |
| 按正常顺序改日期 | 先改开始再改结束会提交倒置区间，出现422 | 跨过另一端时自动对齐，单次应用有效范围 |
| 生成当前范围 | 未编辑过的面板也保留旧范围 | 未编辑且无运行任务时跟随当前阅读；草稿和任务范围保留 |
| 找不到商品或收藏 | 分类恢复按钮不能清掉关键词等条件，收藏空状态和统计混用范围 | 真实清除筛选，商品保留出售／求购分区；区分筛选无结果与真正无收藏，数量范围一致 |
| 按群浏览消息 | 不填关键词点击查找，没有有效下一步 | 聊天消息指定群后可直接浏览；未指定群时给出输入要求，不暗中扩大范围 |
| 清空搜索 | 刷新后重新出现旧关键词与结果 | 当前空查询同步地址，刷新后仍是当前状态 |
| 修改设置 | 保存后继续修改仍显示已保存 | 提示实际未保存状态；还原值不误报，保存失败信息保留 |
| 测试新 Key | 输入新 Key 后测试的其实是旧配置 | 明确为“测试已保存连接”，有新 Key 草稿时提示先保存 |
| 理解常用动作 | 详情、来源、完整摘要、重试等需悬停猜图标 | 保留可见动作文字，不再重复浮层提示；星标、关闭和分页等常用图标仍紧凑 |
| 小屏操作 | 长标题挤走关闭按钮、范围标题只占半行 | 关闭保持右上方，范围利用整行，动作保留44px触屏高度 |

## 边界

这些是按任务复核得出的具体改善，不把测试通过等同于所有用户都会满意。没有调用真实AI或QQ来验证，也没有在真实聊天库执行测试写入；维护动作在测试环境拦截。自动运行时间编辑仍沿用现有设置入口，本轮未扩展计划编辑或重排整个信息架构。

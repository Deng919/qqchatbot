# QQ Digest 核心闭环补全设计

## 目标

补齐设计文档已经声明但当前运行链路没有完整实现的功能，不增加服务器同步、媒体归档或公网部署等新范围。

## 群组配置闭环

- `/api/groups` 返回 `keywords` 和 `collection_window_days`。
- PATCH 支持更新这两个字段，并验证关键词为字符串数组、采集窗口为 1 到 365 天。
- 群组页提供关键词文本框和采集天数输入框；关键词以逗号分隔。
- 摘要调用把当前群关键词写入 user prompt，要求模型优先识别相关讨论，但不得为关键词降低候选标准。
- 首次/无游标同步继续使用该群自己的采集窗口。

## 空消息和失败可见性

- 当摘要时间窗没有归档消息时，不调用 AI、不创建空报告，仍视为该群已完成检查。
- `/api/jobs` 返回截断后的错误文本。
- 总览页失败任务显示可展开/悬停查看的错误原因，并继续对外部文本执行 HTML 转义。

## QQ Bot 审核指令

- 保留现有英文斜杠命令。
- 增加中文指令：`候选`、`入库 12 13`、`忽略 14 原因`、`稍后 15`、`查看 12`。
- `/confirm` 和 `入库` 支持一次确认多个候选；逐条执行并返回汇总。
- 单条失败不回滚已经成功确认的其他候选，回复中明确成功和失败编号。
- 本轮不实现脱离候选队列的任意文本直写，避免绕过来源、类型和幂等记录。

## WebSocket 心跳

- 收到 Hello 后发送 Identify，并按服务端 `heartbeat_interval` 启动独立心跳任务。
- 心跳携带最近序列号；收到 Dispatch 时更新序列号。
- 连接关闭、监听器停止或重连前取消心跳任务，避免后台任务泄漏。
- 网络调用和消息处理不记录 token 或私信内容。

## 验收

- 群配置 API、页面和摘要 prompt 三层字段一致。
- 空消息群不触发 AI。
- 失败任务错误在 API 和页面可见且安全转义。
- 中文批量入库与英文命令兼容。
- 心跳按服务端间隔发送并可停止。
- 全量自动化测试、编译检查和桌面/手机浏览器检查通过。

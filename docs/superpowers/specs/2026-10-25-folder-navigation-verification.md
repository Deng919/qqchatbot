# 顶部后退／前进导航

## 行为

- 页面标题前增加灰阶后退、前进箭头，无可用方向时置灰，支持 Alt+左／右。
- 复用桌面 Chromium/WebView 的浏览历史，不维护第二套导航栈。
- 摘要阅读方式、群聊、日期、页码和全文打开状态接入历史；每个历史条目保存各自的阅读条件、展开状态和列表滚动位置。
- 返回同一文档的旧条目时重新读取该条目，阻止离开前的异步响应或 pagehide 保存覆盖目标状态。
- 跨页面返回保留“上次打开后新增”的原时间基准；启动时尚未读取完成的基准不当作有效值恢复。
- 登录、启动页和 API 不作为顶部箭头可返回的目标。
